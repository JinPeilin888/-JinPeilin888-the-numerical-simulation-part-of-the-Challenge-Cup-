# MGC-01 水下柔性光缆二维动态铺放仿真

本项目以任务书中的 0.52 mm 光缆为主，建立二维集中质量—离散弯曲杆模型，支持 AUV 速度、离底高度、放缆速度、均匀流和海床地形输入。正式配置使用水池淡水 `1000 kg/m³`、最低破断力 `500 N`、安全系数 `3`，并持续强制 `37.5°` 出缆方向。

## 1. 已实现的关键修正

- 放缆长度分布到出口前 8 个 ALE 单元；节点按位置、速度、应变连续的局部分裂插入。
- 最终导向段是固定空间导向储备段，不计入活动缆张力和应变。
- 初始 Bézier 缆形同时满足出口切向和无应变弧长，避免细网格初始压缩。
- 采用轴向 Kelvin–Voigt 阻尼、能量型转角弯曲力和耗散功率非正的弯曲阻尼。
- 10% 抗压正则是 1 mm 网格稳定性对照得到的最低可行值；报告张力仍只统计正轴力。
- 每次运行清理不再生成的旧事件、快照、错误和图片文件，避免旧结果混入新结果。

## 2. 约束与验收门槛

- 出口方向最大误差 `≤ 1e-6°`；
- 无应变总长度守恒误差 `≤ 1e-9 m`；
- 原始最大活动张力 `< 166.667 N`，且 `< 500 N`；
- 动态最小弯曲半径 `≥ 15D = 7.8 mm`；
- 海床穿透 `≤ 1 mm`；
- 最小几何/无应变段长比 `≥ 0.90`；
- 插入后的最短物理单元 `≥ 0.5 ds`；
- 插入瞬时张力跳变 `≤ 0.001 N`；
- 正式 `0.5 s` 工程趋势相邻步差 `≤ 0.0001 N`。

安全判定始终使用未滤波原始张力。`max_tension.png` 和 `tail_tension.png` 显示中值去脉冲后的 0.5 s 工程趋势；对应的 `*_raw.png` 与 CSV 保留全部原始峰值，避免用绘图平滑掩盖安全风险。

## 4. 60 工况矩阵

`configs/cases.csv` 必须严格包含下列笛卡尔积，程序会检查重复、缺失和额外组合：

- `v_A = 0.10, 0.20, 0.25, 0.30 m/s`；
- `H = 0.30, 0.50, 1.00 m`；
- `v_out/v_A = 0.90, 1.00, 1.05, 1.10, 1.20`。

总数为 `4 × 3 × 5 = 60`。批算输出 `sweep_summary.csv/json`、`sweep_validation.json` 和四张对比图；若任一工况的数值、力学、网格或曲线门禁失败，命令返回非零状态。
